# Internationalisation (i18n)

SuperviseMe ships with built-in multilingual support powered by **Flask-Babel**. The UI is fully translated into **English** and **Italian**, with a language switcher available in every page header.

---

## Switching Language

Users can switch the interface language at any time using the 🌐 globe button in the navigation bar. The preference is stored in the session and persists across pages.

---

## Supported Languages

| Code | Language | Status |
|------|----------|--------|
| `en` | English | ✅ Full |
| `it` | Italiano | ✅ Full |

## Adding a New Language

1. **Add the locale to `babel.cfg`** (already present in the repo root).

2. **Extract strings** from templates and Python source:

    ```bash
    pybabel extract -F babel.cfg -k lazy_gettext -o messages.pot .
    ```

3. **Initialise** the new locale (e.g. French):

    ```bash
    pybabel init -i messages.pot -d superviseme/translations -l fr
    ```

4. **Translate** `superviseme/translations/fr/LC_MESSAGES/messages.po`.

5. **Compile**:

    ```bash
    pybabel compile -d superviseme/translations
    ```

6. Add `fr` to the `LANGUAGES` list in `config.py`.

## Lazy translations

String marking follows Flask-Babel conventions:

```python
from flask_babel import lazy_gettext as _l

class LoginForm(FlaskForm):
    email = StringField(_l("Email address"), ...)
```

In Jinja2 templates:

```html
{{ _("Welcome back, %(name)s!", name=current_user.display_name) }}
```
